# Abo JoJo Training Center 💪

Full Muscular System · نظام العضلات الكامل

An **offline, bilingual (Arabic/English) gym web app** — a single `index.html` file with a local library of 131 exercise animations. No internet required after downloading.

**Live app:** https://asadq1q1.github.io/abojojo-training-center/

## Features

- 📚 **Exercise Library** — 131 machine/cardio exercises with animated GIFs, bilingual names (English + العربية), muscle targeting (primary/secondary), equipment info, difficulty badges, and search + filters by muscle group, body area, and equipment.
- 🗓 **My Weekly Plan** — 7-day planner (Monday–Sunday, today highlighted). Set a focus per day (Full Body, Push, Pull, Legs, Cardio, Rest…), add exercises, edit sets, and type weights in **KG or LBS with automatic live conversion**.
- 📝 **Notes** — per-exercise notes with text and/or an uploaded photo.
- 🖨 **Weekly Summary** — print-ready view of the whole week.
- 📋 **Copy last week's plan** — one click to duplicate the previous week.
- 💾 Everything persists in your browser's `localStorage` — fully offline.

## Run it

**Option 1 (easiest):** open the live link above.

**Option 2 (offline):** download the repo (green *Code → Download ZIP*), unzip it, keep `index.html` and the `gifs/` folder together, and double-click `index.html`.

Works in any modern browser on Mac, Windows, Linux, or mobile.

## Structure

```
index.html   ← the entire app (HTML + CSS + JS + exercise data)
gifs/        ← 131 exercise animation GIFs
```
